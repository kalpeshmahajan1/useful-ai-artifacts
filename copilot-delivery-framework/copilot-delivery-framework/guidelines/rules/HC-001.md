## Rationale
Logs are copied, retained and shared far beyond clinical access controls; leaking identifiers is a privacy incident.

## Bad
```
log.Info("Opened study for " + patient.Name);
```

## Good
```
log.Info("Opened study " + internalStudyKey);
```

## Notes
Applies to test fixtures too: use synthetic data only. Human reviewer decides what counts as identifying in this product.

## Rationale
Blocking under the ASP.NET/UI synchronization context can deadlock and exhaust threads under load.

## Bad
```
var data = service.LoadAsync().Result;
```

## Good
```
var data = await service.LoadAsync();
```

## Notes
Heuristic check (verify): '.Result' may be a non-Task property. A human confirms.

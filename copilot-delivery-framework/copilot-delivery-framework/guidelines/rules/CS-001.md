## Rationale
The product compiles with C# 7.3 on .NET Framework 4.8; newer syntax is a compile error or requires an unsupported language-version override.

## Bad
```
var r = x switch { 1 => "a", _ => "b" };
```

## Good
```
switch (x) { case 1: r = "a"; break; default: r = "b"; break; }
```

## Notes
Do not raise LangVersion to make a change compile; that is an architecture decision (ADR).

## Rationale
Leaked subscriptions cause memory growth and duplicate handlers in long viewing sessions.

## Bad
```
this.svc.data$.subscribe(...) in ngOnInit with no teardown.
```

## Good
```
Use the async pipe or takeUntilDestroyed().
```

## Notes
Reviewer checks the project's established teardown pattern first and follows it.

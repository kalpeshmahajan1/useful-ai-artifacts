## Rationale
Replacing the prototype drops 'constructor', breaking instanceof-adjacent logic and debugging.

## Bad
```
Foo.prototype = { run: function(){} };
```

## Good
```
Foo.prototype = { constructor: Foo, run: function(){} };
```

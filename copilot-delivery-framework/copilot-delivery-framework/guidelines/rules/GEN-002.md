## Rationale
Consistency lowers cognitive load; unrelated edits hide the real change and create merge conflicts.

## Bad
```
Reformatting a whole file while fixing one bug.
```

## Good
```
Only the lines needed for the change are touched; new code looks like its neighbours.
```

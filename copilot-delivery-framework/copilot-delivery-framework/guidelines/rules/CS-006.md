## Rationale
Concatenated SQL enables injection and defeats plan caching.

## Bad
```
cmd.CommandText = "SELECT ... WHERE Id=" + id;
```

## Good
```
cmd.CommandText = "SELECT ... WHERE Id=@id"; cmd.Parameters.AddWithValue("@id", id);
```

## Notes
Heuristic check (verify): confirm the concatenated value is not a constant.

## Rationale
Copying .NET Core/modern examples compiles on the author's machine only or silently adds dependencies to a validated product.

## Bad
```
Using Span<T>-based or System.Text.Json code copied from a .NET 8 sample.
```

## Good
```
Use the equivalent already used in the module, or raise an ADR for the new package.
```

## Notes
Reviewer must check the csproj/packages.config before claiming an API is or is not available. If unsure: confidence 'verify'.

## Rationale
Secrets in history are compromised permanently and the product is deployed to many institutions.

## Bad
```
var pwd = "P@ssw0rd1";
```

## Good
```
Read from secure configuration / secret store.
```

## Notes
Static check is a heuristic (confidence: verify). A human confirms before treating as a leak.

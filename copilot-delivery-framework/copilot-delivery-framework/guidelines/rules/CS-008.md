## Rationale
SOLID violations are the main source of rework found in review.

## Bad
```
A controller that parses DICOM, queries SQL and formats the response.
```

## Good
```
Controller delegates to a service; service uses the existing data-access abstraction.
```

## Notes
Size signals (very large class, many constructor dependencies) are prompts for scrutiny, not violations by themselves.
